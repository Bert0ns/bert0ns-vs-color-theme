# bert0ns-vs-color-theme README

Copied Eva dark bold theme, but improved IDE text contrast

## Installation

To install this theme locally:

1.  **Package the extension:**
    Run the following command in the terminal to create a `.vsix` file:

    ```bash
    npx @vscode/vsce package
    ```

2.  **Install the extension:**
    You can install the generated `.vsix` file using the command line:

    ```bash
    code --install-extension bert0ns-vs-color-theme-0.0.1.vsix
    ```

    Or manually in VS Code:

    1.  Go to the **Extensions** view.
    2.  Click the **...** (Views and More Actions) menu.
    3.  Select **Install from VSIX...**.
    4.  Choose the `bert0ns-vs-color-theme-0.0.1.vsix` file.
